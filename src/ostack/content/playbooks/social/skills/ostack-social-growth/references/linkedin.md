# LinkedIn

Off by default. Use this file only for a person whose `social/accounts.md` has `LinkedIn: on`; LinkedIn restricts
accounts for automated activity more strictly than X or Instagram, and every run is at the person's own risk.

## Already commented

The person's comments: `https://www.linkedin.com/in/<handle>/recent-activity/comments/`. Note the posts from the last
week already commented on.

## Find posts

- Content search: `https://www.linkedin.com/search/results/content/?keywords=<terms>&datePosted=%22past-24h%22` (or
  `%22past-week%22`). Sort by relevance for strong posts, by latest for fresh ones.
- Click "more" to read the whole post. Open carousels and documents.

## Follow

Use **Follow**, never **Connect**: connection requests are outreach, not this workflow. Follow from the button next to
the name on the post, or the profile's More menu when only Connect shows. Skip recruiters, agencies selling a service,
company pages and existing connections.

## Comment

Same short voice as everywhere else. Do not repost on LinkedIn.

## Limits

On "You've reached the weekly limit", "unusual activity", a security check or a restricted account, stop LinkedIn for
the day. If the account itself is restricted, stop and report it, since other workflows may use the same account.
