# Comments

Every comment should read like the person typed it in ten seconds because the post was actually worth reacting to. The
team's `social/comments.md` and the person's `social/voice.md` win over anything here.

## Before writing

1. Read the whole post: text, image, every slide, the linked article, and for video what is said and shown.
2. Read the top comments. Do not repeat a point, joke or question that is already there.
3. Find the one specific thing worth reacting to: a number, a claim, a line, a detail in the video.
4. Pick one move: react to that number or line, ask a sharp question only someone in the niche would ask, push back on
   the claim, or make a joke about it.
5. If nothing specific comes to mind, do not comment. Like it and move on.

## How it looks (unless the team's file says otherwise)

- One line, usually under 20 words, using the post's own words and numbers so it is obviously about this post.
- The same voice on every platform. Not longer or more polished because it is LinkedIn.
- An emoji only when it lands. Most comments have none.

## Never

- Stock phrases: "great point", "so true", "love this", "this" alone, "100%", "game changer", "insightful", "spot on",
  "nailed it", "underrated", "one thing I'd add", "curious if".
- Em dashes, hashtags, or tagging tools and companies.
- Summarizing the post back to the author, or starting with "Great", "Love" or their name.
- Pitching, linking anything, or hinting at what the team sells.
- Made-up experience ("when we tried this...") unless the person gave you that story.

## Vary it

In one run no two comments start with the same word or follow the same shape. After drafting a batch, read them
together; if they look like a template, rewrite the ones that match.
