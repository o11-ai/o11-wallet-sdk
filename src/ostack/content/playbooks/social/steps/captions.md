Write one caption per platform in the plan, following the captions reference in the skill, refined by
`social/captions.md` and then by the row's prompt. When the post has a video, write from what the final cut actually
says and shows, after it is made, so the caption and the video never disagree.

Draft every extra the row or the team's file asks for (a thread, a first comment with the link, alt text), labeled so
the team knows where each goes. Read all of a row's captions together before writing them back: each should read as
written for its platform, not one caption trimmed three ways.
