# o11

TypeScript SDK and o11 CLI for wallet tool access. The SDK runs in Bun or Node.js 22+.

Install the CLI with nothing else needed: `curl -fsSL https://go.o11.ai/install.sh | sh` (macOS, Linux) or `irm https://go.o11.ai/install.ps1 | iex` (Windows). This package's CLI requires Bun: `bun install --global @o11/sdk`, then run `o11 --version` and confirm product `wallet` and package `@o11/sdk`. If another command named `o11` is already installed, use the exact command returned by the checksum-verified installer in the guide.

Guides: https://docs.o11.ai/
