# o11

TypeScript SDK and o11 CLI for wallet tool access. The CLI requires Bun; the SDK runs in Bun or Node.js 22+.

Install the CLI with `bun install --global @o11/sdk`, then run `o11 --version` and confirm product `wallet` and package `@o11/sdk`. If another command named `o11` is already installed, use the exact command returned by the checksum-verified installer in the guide.

Guides: https://docs.o11.ai/
